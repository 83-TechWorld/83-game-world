About Block Builder: a free game for ages 4-8

Block Builder is a free building and memory game for children. Kids pick colours and fill in blueprints for houses, trees, rockets and forts, then try to rebuild them from memory.

Building gives children a reason to look closely. To finish a blueprint they need to notice each colour, see where it belongs and work carefully across rows and shapes. Memory levels add a fresh challenge by showing the picture first and then taking the colours away, so a child must hold the design in mind. Finished houses, trees, rockets and forts give a satisfying result that makes children want to build one more.

How to play

Pick a colour, then tap the matching box in the blueprint. In memory levels, look carefully first, because the colours disappear.

Controls

Use a finger or a mouse. Pick a colour from the palette, then tap the box it belongs in. On memory levels, study the picture before it disappears. The speaker button changes sound, and the Levels button goes back to the map.

Skills kids practise

  • Colour recognition
  • Patterns and shapes
  • Visual memory
  • Planning and focus

For parents and teachers

Before a memory level, ask your child to describe the picture aloud, such as “red roof, blue door”. Putting what they see into words is a helpful memory trick. Afterwards, rebuild a simple design with real blocks or coloured paper, then swap roles and let your child set the challenge for you.
